# canvas-scan v0.5.0 release notes (draft)

This draft adds one selected-canvas explanation for the next interaction. The
capture is bounded to ten seconds. It can show the first normalized command
difference, no observed difference, or an honest unknown. It includes bounded
generated and same-origin mapped callsite evidence, explicit same-type finding
comparison with measured pair deltas, and versioned JSON artifacts.

The v0.4 recording API and its full passive performance gates remain unchanged.
This feature does not prove pixels, GPU or compositor work, cause, automatic
matching, or improvement. It does not fetch cross-origin source maps. Detail is
selected only and has fixed collection limits.
