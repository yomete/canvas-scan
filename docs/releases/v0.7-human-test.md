# v0.7 pre-publication human test

Prerequisites: use the exact tarball hash from the pack job, real Chrome, no
publication credentials, and a clean disposable consumer.

Steps 1 to 5 need an application built the way you ship one: minified, with
source maps published, and with at least one canvas the framework did not
create. Do not use the demo. The demo is a development build, and it cannot fail
the way this release exists to fix.

1. Confirm a finding on a minified build names a file you wrote, not the bundle.
2. Confirm a canvas created imperatively carries a source location.
3. Confirm a minified owner reads as **Minified owner**, and never heads a finding alone.
4. Confirm findings with no measured time are collapsed behind a count.
5. Confirm the coverage line says so when most frames come back unknown.
6. Confirm a recording that hit the canvas limit says which canvases are summaries only.
7. Confirm a comparison refuses that recording rather than comparing it.
8. Confirm the network panel shows no request except your own application's, and same-origin source maps.

Use this exact record:


A person owns this run, the signing, the tag, the publication, and the final
release approval.
